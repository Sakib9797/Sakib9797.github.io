Projects

Government Service Navigation Agent

Code

0% hallucination across a 61-case automated eval

A bilingual (Bangla/English) RAG agent that answers questions about Bangladeshi government services: fees, required documents and procedures.

  • LangGraph
  • FAISS
  • RAG
  • LLM
  • Python
  • Five-stage LangGraph pipeline with FAISS retrieval, multilingual sentence-transformer embeddings, a constrained LLM layer and automatic language detection.
  • Reverse-engineered two Bengali PDF text decoders, one by recovering a corrupted ToUnicode CMap and one by mapping the legacy Bijoy/SutonnyMJ encoding, so government gazettes became machine-readable.
  • Every number the LLM generates is checked against source records, and facts are rendered from a validated JSON Schema. Grounding and safety gates fail the build on any violation.

Multi-Target Domain Adaptation for Semi-Supervised Object Detection

Code

57% balanced mAP · rainy domain 30% → 57%

A YOLOv11s detector that adapts across normal, foggy and rainy conditions using an adversarial domain classifier and MMD feature alignment.

  • PyTorch
  • YOLOv11
  • Domain Adaptation
  • Semi-Supervised
  • A 3-stage dynamic curriculum scheduler gradually increases domain difficulty, which improved rainy-domain detection by 90%.
  • Semi-supervised pseudo-labeling with confidence thresholds stepped down from 0.6 to 0.4 to 0.2 and progressive data inclusion lets the model learn from unlabeled target-domain data.
